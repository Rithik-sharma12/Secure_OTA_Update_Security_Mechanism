# Repository tree

A map of every folder and the files that matter, with what each one is for. Paths are relative to the repository root. Generated folders (`node_modules/`, `.next/`, `__pycache__/`, `.pio/`, `.venv/`) and git-ignored secrets are listed only where you need to know they exist.

Legend: **[ignored]** = git-ignored, never committed. **[generated]** = created by a tool, safe to delete.

## Top level

```
.
├── apps/                    Applications: console, gateway, local agent
├── firmware/                ESP32 firmware (PlatformIO)
├── scripts/                 Launchers and automation scripts
├── deploy/                  Deployment configuration (Cloudflare Tunnel)
├── docs/                    Documentation and images
├── assets/                  Source brand assets
├── .github/workflows/       CI and firmware release pipelines
├── docker-compose.yml       Base stack: gateway + console
├── docker-compose.local.yml LAN-only overrides
├── docker-compose.cloud.yml Adds the Cloudflare Tunnel container
├── docker-compose.hub.yml   Runs prebuilt images from Docker Hub
├── package.json             npm workspace root; scripts proxy to apps/web
├── package-lock.json        npm lockfile for the workspace
├── .env.example             Template for .env.docker (all stack variables, commented)
├── .env.docker              [ignored] Real secrets for Docker
├── .gitignore               Root ignore rules (secrets, keys, local stores)
├── .dockerignore            Keeps venvs, node_modules and env files out of images
├── .npmrc                   npm settings
├── README.md                Project overview, setup and reference
└── Tree.md                  This file
```

| Path | Purpose | Notes |
|---|---|---|
| `gateway_keys/` | [ignored] Older local copy of the gateway's Ed25519 keys | The gateway reads keys from `apps/gateway/gateway_keys/` when run locally and from a Docker volume in containers |

## apps/gateway: the edge gateway

FastAPI service on port 5000. Python 3.11 in Docker.

```
apps/gateway/
├── edge_gateway.py          App entry point (uvicorn edge_gateway:app)
├── gateway/
│   ├── config.py            Environment settings, paths, limits
│   ├── auth.py              API key and per-device token checks
│   ├── crypto.py            Ed25519 key management and release signing
│   ├── package.py           Secure package format (AES-256-CBC + RSA-2048)
│   ├── release.py           Release catalogue and per-architecture manifests
│   ├── factory.py           Merged first-flash image for blank boards
│   ├── deployment.py        Deployment lifecycle and gates (architecture, quarantine, timeout)
│   ├── commands.py          Remote commands delivered in heartbeat responses
│   ├── history.py           SQLite telemetry (7 days) and audit trail (50,000 rows)
│   ├── audit.py             Audit middleware
│   ├── state.py, models.py, utils.py   Shared state, request models, helpers
│   └── routes/              HTTP routes: heartbeat, devices, releases, deployments, dashboard, live, github, health, operations
├── tests/                   pytest suite (201 tests)
├── requirements.txt         Python dependencies
├── pytest.ini               Test settings
├── Dockerfile               Production image
├── README.txt, RPI_DEPLOY.md  Running on Windows and Raspberry Pi
├── gateway_keys/            [ignored] Ed25519 signing keys, created on first start
└── gateway_firmware_cache/  [ignored] Device registry, manifests, cached firmware, history.db
```

## scripts

| File | Purpose |
|---|---|
| `build-firmware.cmd` | Windows: builds the ESP32 firmware and the images the console needs (`firmware/dist/`) |
| `start-dev.cmd` | Windows: starts the gateway (if not running) and the console on port 3000 |
| `start-gateway.cmd` | Windows: starts the gateway on port 5000 with the API key from `apps/web/.env.local` |
| `start-agent.cmd` | Windows: starts the SecureOTA USB agent on 127.0.0.1:17317 (start-dev.cmd opens it too) |
| `go-online.cmd` | Windows: publishes the Docker stack through Cloudflare (`on`, `status`, `logs`, `off`); writes `deploy/last-run.log` |
| `acceptance-test.ps1` | Runs the acceptance checklist against a disposable stack |

Every script changes to the repository root first, so they work from any folder.
