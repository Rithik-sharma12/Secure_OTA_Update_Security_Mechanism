# OTA_IOT Documentation Index

This folder contains non-runtime assets, planning materials, and project knowledge artifacts.

## Folders

- `guides/` - Security guides and implementation references
- `reports/` - Final and intermediate reports
- `research/` - Literature review and AI-assisted findings
- `references/` - External links and source references
- `presentations/` - Slides, poster content, and presentation files
- `patents/` - Patent forms, drafts, and supporting files
- `planning/` - Planning notes and requirement definitions
- `diagrams/` - Architectural and workflow diagrams
- `Final/` - Final exported/project-completion assets

## Subsections Added During Cleanup

- `research/ai-search/` - Consolidated AI search result files
- `reports/legacy/` - Archived old report folder content
- `patents/model-patent/` - Model patent documents
- `patents/patent-assets/` - Patent form assets
- `patents/patent-draft/` - Patent draft package and markdown sources
