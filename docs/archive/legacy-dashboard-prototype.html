Why Ed25519?
✓ Only ~1.5KB RAM for verification
✓ Faster than RSA-4096 by 100x
✓ 128-bit security level
✓ Deterministic — no random oracle needed
✗ RSA-4096 requires ~64KB RAM (unusable)
✗ TLS 1.3 requires OS-level support
Integrity vs. Confidentiality
Our focus: Integrity (Signing)
Open-source firmware doesn't need encryption — everyone can read the code.
What matters: did the authentic build server sign this binary?
Answer: Ed25519.verify(sig, bin, pubkey)
